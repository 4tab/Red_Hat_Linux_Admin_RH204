	Organizing local users and groups:
	view all users cat /etc/passwd

	sudo -i -u user2 -> logs in to user2's interactive shell
	sudo rm /usr/bin/badapp removes badapp binary in a dirty fashion
	now in sudo -i we have launshed a root(priviledged) shell:
	useradd user1
	passwd user1 - set passwd for user1 so they can login:
	passwd -l user1 - locks account, -u unlock the acoount
	usermod - modifies user eg -s /bin/zsh user1 change user shell to zsh
	
	groupadd devs- adds new group devs
	groupmod -n(name) developers(new name) devs(old name)
	groupdel developers deletes developers group
	userdel user1 deletes user1 but keeps user1 home dir add -r to rm home dir , this is not recommended due to uid reassignment for new users so rather lock the account
	id user1 shows(integer) user and group id 
	
	find(find files) /(from root dir) -uid(owned by user id) 1001 2>/dev/null (errors to void)

	File Permissions
	1 = x = execute = access
	2 = w = write = change
	4 = r = read = see
	so 5  = rx =execute / run, 6 = wr, 7 =wrx

	each file has Owner, owning group, other - everyone else
	so 750 Owner can rwx, those in group can rx , everyone else cannot get to this file
	chmod 744 file1 , owner rwx , group and everyone else can read only
	chmod -R 744 /Books does the same but everything in book folder and deeper will have these permissions applied

	chown user1 file1 - change ownership of file1 to user1
	chown :devs file1 - devs group give new owners of file 1
